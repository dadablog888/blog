# 기간별 네이버 블로그 갱신

- 게시물 ID별 JSON을 원본으로 저장하고 기존 HTML 주소를 유지한다.
- KST 날짜로 전체 공개 목록을 순회해 요청한 월/일의 글을 찾는다. RSS 최신 목록만으로 과거 전체를 판단하지 않는다.
- 대상 원문은 기존 글도 다시 읽고 텍스트·제목·게시일·분류 해시로 변경을 판별한다.
- 원문 확인 자료와 실행 결과를 보관하고, 새 글/변경 글만 검토한 소개 데이터로 적용한다. 접근 실패·삭제 의심은 기존 자료를 지우지 않는다.
- 재실행 시 중복 없이 같은 결과를 내는 수집·검토·적용 도구와 재사용 스킬을 만든다.
- 2026년 8월 전체를 실제로 정리하고 페이지·사이트맵·재실행 동작을 검증한다. 커밋·push·예약 작업 생성은 하지 않는다.
