# 중국 콘텐츠 소개 사이트 구현 계획

- 기존 저장소, GitHub Pages 주소와 배포 설정을 확인한다. 커밋과 push는 하지 않는다.
- 네이버 블로그의 최근 공개 게시물 10개를 확인하고 제목, 게시일, URL, 확인한 핵심 내용과 검색 키워드를 기록한다. 접근하지 못한 내용은 추측하지 않는다.
- 의존성 없이 제공되는 정적 메인 페이지, 주제별 탐색, 글별 고유 소개 페이지를 만든다.
- 고유 메타데이터, 내부 링크, self canonical, Open Graph, 확인 가능한 구조화 데이터, sitemap과 robots 안내를 적용한다.
- 실제 /blog/ 경로에서 로컬 HTTP 응답, 내부 링크, 원문 URL, 메타데이터와 모바일 레이아웃을 검증한다.
- 변경 파일과 검증 결과, Pages 배포 및 Search Console 후속 작업, 제안 커밋 메시지를 정리한다.

## 추가 요구 반영

- 사진과 장식 이미지를 제거하고 간결한 텍스트 문서로 구성한다.
- 메인은 최신 10개, 전체 글은 누적 보존한다. 연도·월별 아카이브와 주제별 30개 단위 정적 페이지를 생성한다.
- 새 글 추가, 월·연도 전환, 페이지 나누기에서도 과거 URL과 탐색 링크가 유지되는지 검증한다.
