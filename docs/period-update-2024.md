## 출처와 확인 범위

원문 제목·분류·URL·KST 게시 시각과 정규화한 본문 해시를 저장했다. 게시 시각은 확인 가능한 분 단위 정밀도로 표시한다. 소개 검토일은 2026-10-24이다. 원문 전문은 Git에서 제외하는 `.cache/blog-sync/2024-MM/sources/`에만 보관한다.

사진·영상·이미지 내부 글자 전체 및 원문이 인용한 외부 자료를 모두 검증한 것은 아니다. 과거 가격·예약·정책·순위·건강·시술 설명은 당시 자료나 개인 경험으로 구분했다. 가사·시·외부 기사 전문을 소개문에 복제하지 않았다. 본문이 행사 안내 링크뿐인 글은 그 범위로 소개하고 개별 noindex도 명시했다.

`searchStrategy: naver-first`와 모든 HTML의 `noindex, follow`를 유지한다. 네이버 원문 링크를 표시하고 GitHub noindex URL을 검색 사이트맵에 싣지 않는다. 커밋·푸시·배포는 실행하지 않았다.
