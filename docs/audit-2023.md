## 로컬과 공개 사이트의 차이

로컬에는 2023년 JSON과 소개 페이지 182개가 생성되어 있지만 모두 아직 Git에 추가되지 않은 상태다. 현재 공개 사이트의 `/blog/archive/2023/`는 HTTP 404이며 `/blog/archive/`에는 2023년 링크가 없다. 따라서 기존의 적용 완료는 로컬 작업 완료를 의미하며 공개 사이트 반영 완료가 아니다. 커밋·푸시·배포는 이번 재점검에서도 수행하지 않았다.

확인 범위는 현재 네이버 공개 목록과 정규화된 본문이다. 비공개·삭제된 글이나 이미지·영상 안의 내용까지 확인했다는 의미는 아니다. 2022년 이전 작업은 재개하지 않았다.
